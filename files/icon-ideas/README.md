# WhoAped icon directions

All concepts use the current WhoAped palette:

- Ledger ink: `#111313`
- Warm paper: `#F4F4EF`
- Signal orange: `#F04B2F`

1. **Sonar W** — a cleaner, more literal brand initial.
2. **Transaction Pulse** — live balance movement and instant detection.
3. **Wallet Beacon** — a wallet actively broadcasting an event.
4. **Watch Eye** — continuous monitoring with a detected event.
5. **Block Ping** — one highlighted on-chain event among blocks.
6. **Ape Signal** — the most characterful and literal WhoAped direction.
7. **Orbit W** — a premium, compact monogram.
8. **Detected** — focus brackets around a monitored transaction.
