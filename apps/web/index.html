OPEN SOURCE IS THE POINT

The chain is public.
The tracker should be, too.

Wallet monitoring shouldn’t be a black box. WhoAped is open source, so the code behind transaction parsing, dust filtering, and alerts can be inspected and improved by anyone.

↗Explore the code on GitHubRead the source, report issues, or contribute.

THE SIGNAL

Wallets move onchain.
You stay in the loop.

A transaction hash is not a useful update. WhoAped shows what changed in the wallets you follow, without the noise of raw instructions.

HOW IT WORKS

Three steps. No noise.

01

Add a wallet

Save any public Solana address and give it a name you will recognize.

02

We watch the chain

WhoAped tracks new activity and filters out tiny, unsolicited dust transfers.

03

See what changed

Get a readable activity record and a push alert for meaningful wallet moves.

BUILT FOR THE DETAILS

More than a transaction hash.

See what a wallet actually did: both sides of a swap, the asset and protocol behind a deposit, or the details of a token launch. A readable record, not a wall of instructions.
